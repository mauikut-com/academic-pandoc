# Scene 02 — Baseline (keyframes)

## Start frame

Still image, 16:9. High-quality 3D animated explainer in the style of Zack D
Films. Interior of a clean 3D data center under calm blue lighting. A single
glowing server rack sits center-right with steady cyan status lights. On the
left, a stylized smartphone shows the Cimory storefront with a milk carton, a
yogurt cup, and a sausage pack. A stylized finger hovers just above the "Order"
button, about to tap. Soft volumetric light, glossy 3D CGI, dark navy
background. No motion blur.

## End frame

Still image, 16:9. Same data center and rack. A glowing cyan order packet sits
on the return path beside the phone, a green checkmark pops above the storefront,
and a floating holographic readout reads "Order placed — 0.8 s". The rack's
status lights glow steady cyan. Calm blue lighting, glossy 3D CGI, crisp
legible readout text.

## Negative

photorealistic, live action, real human hands, film grain, blurry, low detail,
text artifacts, misspelled words, any logo other than Cimory, red or orange
lights, more than one server rack, harsh flat lighting
