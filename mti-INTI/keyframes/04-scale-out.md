# Scene 04 — Scale-out (keyframes)

## Start frame

Still image, 16:9. High-quality 3D animated explainer in the style of Zack D
Films. A glowing translucent load balancer has just appeared in front of an
overloaded server rack, and the rack is mid-clone: two glowing server racks now
stand where there was one, with a third fading in. Cyan traffic lanes begin to
split toward the new racks. Dark navy data center, neon cyan accents, glossy 3D
CGI, floating holographic UI. No motion blur.

## End frame

Still image, 16:9. Eight glowing server racks stand in a neat row, status
lights a steady green. Traffic flows through parallel cyan lanes into each
rack, and the queue has fully drained. A holographic latency readout has
dropped back to a low value, and a caption reads "Scale out: add servers."
Glossy 3D CGI, dark navy background, crisp legible caption and readout text.
