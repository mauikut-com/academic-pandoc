# Scene 06 — Right-sizing (keyframes)

## Start frame

Still image, 16:9. High-quality 3D animated explainer in the style of Zack D
Films. A central glowing gauge with a smooth demand curve running across it.
The curve is rising, and a smart autoscaler — a glowing control node — is
spawning a new glowing server rack in response. A few racks are already present
with calm cyan-green status lights. Dark navy background, neon cyan accents,
floating holographic UI, glossy 3D CGI. No motion blur.

## End frame

Still image, 16:9. The gauge's demand curve has settled, and the server racks
now sit balanced with steady cyan-green lights. The autoscaler glows calmly, a
latency line holds flat, and a caption reads "Autoscale: capacity follows
demand." Glossy 3D CGI, dark navy background, crisp legible caption text.

## Negative

photorealistic, live action, film grain, blurry, low detail, text artifacts,
misspelled words, any logo other than Cimory, red or orange lights, abrupt
jumps, cluttered dashboards with unreadable text
